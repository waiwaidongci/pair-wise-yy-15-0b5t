# hxyfront-62014 赛鸽训放记录

面向赛鸽棚的训放记录前端工具：训放场次与成绩排行、健康观察与成绩冻结闭环、逐羽复核、
未归巢提醒、单羽档案、按血统筛选的历史成绩与配对管理。

源提示词编号：9 · 技术栈 React + Vite + TypeScript · 开发端口 62014

## 健康观察 × 成绩冻结闭环规则

- **一场训放唯一**：同一放飞地点和放飞时间只认一场训放，重复提交沿用首次场次与首次结果。
- **冻结退出排行**：健康异常鸽子在观察区间内的未锁定成绩退出排行，并进入逐羽复核；
  同场其他鸽子的成绩不受影响、照常排行。
- **复核锁定**：逐羽复核通过后成绩锁定，回榜并标注「已复核锁定」；锁定不受后续冻结范围重算影响。
- **解除条件**：异常后需**连续两次正常复查**，且两次复查**相隔至少 12 小时**才解除；
  两次正常之间再次异常则计数清零。观察期间禁止该鸽新增训放和配对。
- **更正重算**：旧健康记录可更正（原记录作为历史保留），系统按更正后的时间线重算冻结范围；
  同一条记录连续多次更正以最新更正为准。
- **幂等提交**：每次提交带幂等键，重复点击或并发提交（同键）一律沿用首次处理结果。

## 分层结构

- `src/rules.ts` — 规则层（纯函数）：场次唯一键、健康时间线/观察区间、冻结范围、复核锁定、排行、统计。
- `src/store.ts` — 存储层：`apply(state, action)` 状态转移与幂等表，localStorage 持久化与演示种子数据。
- `src/ui/` — 界面层（React）：订阅同一份状态，列表、排行、统计、档案全部由规则层派生，刷新后一致。

## 页面

- **鸽棚总览**：在册数、归巢率/平均速度、观察中、待复核、未归巢提醒与观察进度（12h 倒计时提示）。
- **训放与排行**：建场次、登记归巢（可按距离/时间自动算速度、标记未归巢），按血统筛选的场次排行。
- **逐羽复核**：冻结成绩卡片化逐羽锁定，已锁定历史可查。
- **健康观察**：登记异常/正常复查、配对登记（观察期拦截）、逐羽时间线与记录更正。
- **赛鸽档案**：登记赛鸽、按血统筛选、单羽训放/健康区间/配对历史。

## 本地运行

```bash
npm install
npm run dev          # http://localhost:62014
npm run typecheck    # 类型检查
npm run verify       # 规则引擎闭环验证（31 项，不依赖浏览器）
npm run build
```

界面内置一套演示数据（含观察中、已解除、已锁定、未归巢等各种状态），可随时点「恢复演示数据」。
