# hxyfront-62014 赛鸽训放记录

面向赛鸽棚的训放记录前端工具，已实现「健康观察与成绩冻结」闭环：

- **同场唯一**：同一放飞地点 + 同一放飞时间（分钟级）只认一场训放；重复或并发提交沿用首次结果（幂等台账）。
- **异常退榜**：登记健康异常后，该鸽所有未锁定成绩立即退出排行；同一场次其他未锁定成绩逐羽复核，复核通过即锁定在榜。
- **解除条件**：连续两次正常复查、且本轮首次复查起相隔至少 12 小时才解除冻结；冻结期间禁止新增训放与配对。
- **黏滞锁定**：已锁定成绩不因后续健康异常退出排行。
- **更正重算**：旧健康记录仅作废不删除（历史保留），更正后冻结范围自动重算，排行/统计联动。
- **一致性**：列表、统计、未归巢提醒全部从同一份持久化状态经纯规则函数推导，刷新页面（及多标签页）后一致。

## 技术栈

React 19 + Vite + TypeScript，无后端，状态持久化在 `localStorage`。

## 架构（规则 / 存储 / 界面分离）

```
src/domain/    规则层（纯函数、唯一裁决者）
  types.ts       领域模型
  rules.ts       同场键、冻结窗计算、成绩在榜推导、统计、操作校验
src/data/      存储层
  seed.ts        演示数据（时间相对加载时刻偏移）
  store.ts       localStorage 持久化、订阅、幂等/并发提交台账
src/ui/        界面层（只消费规则层推导出的视图）
  useApp.ts      React 绑定：统一状态 + 推导视图 + Toast
  OverviewPanel  鸽棚总览（统计、冻结板、未归巢提醒）
  RacesPanel     训放登记 + 成绩排行 + 逐羽复核
  HealthPanel    复查登记、冻结进度、健康时间线更正、配对
  BirdsPanel     鸽棚总览、单羽档案、按血统筛选历史成绩
```

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62014。类型检查：`npx tsc --noEmit`，构建：`npm run build`。
页内「重置演示数据」可随时回到初始演示状态。
